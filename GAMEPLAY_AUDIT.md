# ImGuiMC: native gameplay/rendering audit — 25 октября 2026

В настоящем Minecraft 26.3 с полным установленным комплектом найдены и исправлены два дефекта изображения. Проверены production-классы из вложенного ImGuiMC JAR; тестовый драйвер их не заменяет.

## Исправления и воспроизведение

**Перевёрнутый интерфейс в Vulkan.** `CachedImguiOrthoBuffer` дополнительно переворачивал ось Y по имени backend. Minecraft `RenderTarget` сохраняет нижнее начало координат, а native Vulkan surface blit уже переворачивает изображение для экрана. В результате мир был ориентирован правильно, а окно и текст ImGui — вверх ногами; координаты SDL-клика оставались обычными. Убрана дополнительная смена оси, scissor приведён к тому же соглашению координат.

В исходном прогоне `foundation-2026-10-25-imgui-orientation-baseline-imgui` настоящий зелёный UI-маркер отсутствовал в ожидаемой экранной точке: GPU возвращал `[53,65,86,255]`. Собранный кадр показывает перевёрнутое окно внизу. После исправления тот же маркер находится в левом верхнем углу, точный RGBA — `[0,255,0,255]`; окно и мир ориентированы одинаково. Стандартный GameTest screenshot снимается раньше ImGui, поэтому доказательство использует явное чтение уже собранного target и ту же ориентацию, что Minecraft Screenshot/surface.

**Обрезка окна за краем экрана.** После ограничения минимальной координаты прежняя ширина/высота scissor вычислялась от исходной отрицательной координаты. Видимая область расширялась и пропускала лишнюю геометрию. Теперь ограничиваются обе границы; полностью внешние прямоугольники пропускаются. В `foundation-2026-10-25-imgui-clip-baseline-imgui-components` реальный GPU оставлял **128** непрозрачных красных пикселей вместо **64**. Исправленный renderer оставляет ровно 64; все остальные RGBA-пиксели также совпадают с ожиданием.

## Пройденные проверки

| Область | Реальное действие/результат |
| --- | --- |
| Установленный host | Штатные pre/post callbacks создают окно и typed image в настоящем main target; production handler не переинициализируется. |
| Ввод | SDL cursor warp и настоящие button events нажимают кнопку ровно один раз. Клик по полю и UTF-8 событие дают точную строку `audit λЖ`. Это проверка ввода; набор доступных глифов определяется шрифтом. |
| Ресурсы | Настоящая перезагрузка Minecraft при открытом UI сохраняет введённую строку, восстанавливает font atlas и даёт тот же зелёный пиксель. Ресурсы изображения освобождаются через production `afterDraw`. |
| GPU | Отдельные native contexts проверяют все пиксели RGBA8, RGBA16F, alpha blend, частично внешние и полностью внешние clip rectangles, framebuffer/logical scaling и сохранение caller-owned targets. |
| SDL окна | Созданы настоящие detached window и surface; выполнены acquire/blit/submit/present, resize до 422×274, focus/input и уничтожение. Проверены освобождение удерживаемых клавиш и сохранение основного окна/cursor. Пользовательский clipboard восстанавливается и не записывается в отчёт. |
| Возврат host | После уничтожения временных contexts установленный ImGui host продолжает не менее пяти кадров. |
| Интеграция | Все 11 включённых инспекторов Veil отрисованы, F6 открывает/закрывает overlay; ресурсная перезагрузка при открытом инспекторе проходит. |

Принятые native-профили в `../Aeronautics/build/porting/packaged-smoke/`: **`foundation-2026-10-25-final-imgui`**, **`foundation-2026-10-25-final-imgui-components`** и `foundation-2026-10-25-release-editor`.
